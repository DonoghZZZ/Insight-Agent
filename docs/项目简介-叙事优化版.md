# 洞见 Prism — 飞书表格版（叙事优化）

---

**产品定位**
洞见 Prism 是一款面向研究者和分析师的多 Agent 协同数据分析智能体。聚焦学术舆情分析与跨平台数据挖掘场景，将"采集→清洗→分析→报告"全流程压缩为一句自然语言指令。

**解决问题**
当前数据分析面临三重困境：一是工具链割裂，爬虫、清洗、建模、可视化各需独立掌握，研究者 60% 时间消耗在工程环节而非分析本身；二是跨平台数据整合困难，不同平台的字段结构、反爬机制、数据格式迥异，缺乏统一入口；三是传统分析工具依赖手动配置，字段映射、模型选择、参数调优均需人工介入，无法动态响应追问。

**核心亮点**
洞见 Prism 以自研 AIAgent 引擎（520 模块）为决策核心，实现智能体驱动的全流程闭环：① 自然语言任务分解——用户提出分析意图，Agent 自主完成平台选择、参数配置与采集调度；② 多工具协同编排——Agent 动态调用 8 平台爬虫引擎与 7 个分析模型（情感分析、主题提取、词频统计等），智能字段检测实现零配置即导即用；③ 流式推理与记忆——支持多轮追问下的上下文保持与增量分析，会话状态持久化；④ 双模态交付——终端 CLI + Web UI，37MB 解压即用，MIT 开源。
