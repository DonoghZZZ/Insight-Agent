# 洞见 Prism — AI 数据分析智能体

> **一句话**：说人话就能做数据分析的 AI Agent ——「采集→分析→报告→对话」全闭环，一个人就是一支数据团队。

---

## 一、我们解决了什么问题

做数据分析的痛点大家都知道：学 Python、配爬虫、洗数据、跑模型、画图表、写报告——每一步都是一道坎。更别提做完一轮后老板/导师换个角度追问，又要从头来一遍。

**洞见 Prism** 把这个流程压缩成一句话：「帮我分析小红书上关于AI学习的热门笔记」。

你的角色从「数据分析师」变成「指挥官」——描述需求，AI 负责执行全流程。

---

## 二、核心亮点

### 亮点 1：AI 主持分析，不是 AI 辅助分析 ⭐

市面上的 AI 分析工具大多是「先跑代码，再问 AI」——AI 只是个答疑的 NPC。

洞见的逻辑是：**AI 是主持人，代码是工具**。AI 直接读取数据、动态决定分析方法、写 Python 执行、输出结论、接受追问。就像雇了一个懂代码的数据分析师，你只需要下指令。

```
你：「这些评论的情感倾向如何？」
AI：直接写代码跑 SnowNLP → 输出分布图 + 正负面例句 → 追问「负面主要集中在什么问题？」
你：「再对比一下天猫和京东对同一款产品的评价」
AI：重新加载两个数据集 → 并行分析 → 输出对比结论
```

### 亮点 2：8 平台爬虫 + 自然语言启动 ⭐

| 平台 | 数据类型 |
|------|----------|
| 知乎 | 问答 |
| B站 | 视频弹幕/评论 |
| 小红书 | 笔记 |
| 抖音 | 短视频评论 |
| 知网 | 学术论文 |
| 天猫/京东 | 商品评论 |
| 豆瓣 | 图书/电影评分 |

不需要手动选平台、配参数。说「爬抖音上关于 AI 的视频评论」，AI 自动选择抖音爬虫、设置关键词、启动采集。

### 亮点 3：智能字段检测，零配置 ⭐

不同平台爬下来的数据列名千奇百怪——有的叫「content」，有的叫「评论内容」，有的叫「text」。传统方案需要手动写映射表。

洞见的 `auto_detect_fields()` 自动推断每列类型（文本/数值/日期），对任意平台的数据「即导即用」，真正做到了零配置。

### 亮点 4：520 文件自研 Agent 内核 ⭐

不是调 API 的薄壳。项目内嵌了一个完整的 AIAgent 引擎：

- **懒加载**：只在对话时唤醒，冷启动 130ms
- **工具编排**：Agent 自动选择工具链，全程可视化
- **流式输出**：逐 token 打字机效果，实时可见
- **会话持久化**：分析到一半退出，下次打开继续

### 亮点 5：双界面 + 一键分发 ⭐

- **终端版** (`insight`)：ANSI Shadow 艺术字欢迎页，六宫格菜单，Rich 动画
- **Web 版** (`insight-web`)：Apple 白色极简设计，毛玻璃侧栏，Flask + Chart.js

整个项目 **37MB，解压即用**，一根 U 盘就能带走。MIT 开源协议。

## 四、为什么这个项目值得关注

### 1. 真正的「AI 原生」设计

不是给传统软件加个 AI 聊天框。从架构第一天就以 Agent 为中心——AI 是大脑，爬虫和分析是四肢。这代表了软件交互范式的一次转变：从「人操作工具」到「人指挥 Agent」。

### 2. 完整闭环，不是半成品

市面上很多 AI 项目只做了「对话」这一环。洞见做到了「数据采集→智能分析→可视化报告→多轮问答」全流程打通。用户不需要在 5 个工具之间切来切去。

### 3. 实用主义，不是玩具

8 个平台爬虫都是真实可用的（不是 Demo），分析模型覆盖描述性统计、情感分析、TF-IDF、主题提取、时间序列等学术和商业场景中真正需要的能力。用户的第一反应是「这我真能用上」，不是「挺酷的，但能干嘛」。

### 4. 工程完成度高

懒加载、会话恢复、流式输出、并行分析、自适应布局、配置记忆——这些细节让产品从「能跑」变成「好用」。评委看的不只是想法，更是执行力。
